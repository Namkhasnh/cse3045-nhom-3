Acceptance criteria: Filters match the same visible dish, inclusive exact prices, stable scope/filter cursors and safe missing/hidden 404. Anonymous requests work with auth unavailable.
Tests/evidence: CAT-01, PUBLIC-01, DATA-01; real MySQL filters/pagination and explicit privacy projection assertions.

Preserve exact string IDs/integer VND/eight-place fraction rates, snapshot immutability, actor-scoped durable keys, current ownership, transaction/audit atomicity and documented account-first lock order. No external calls in retried DB transactions; no process-local mutex as race protection.
