## Delivered

Buyer history/detail/recovery routes, current-owner list/detail, scope/filter/sort-bound signed timestamp/ID cursors, durable successful keys without TTL deletion, immutable historical projections. Every page/query scope has one polling owner. Visible/online queries poll about5s, no overlap even when a response is held; hidden/offline abort/pause, return refreshes immediately, error backoff caps30s. Terminal fulfillment switches to payment-only reads while unpaid and stops when paid. Separate order/payment versions reject late responses independently, including replies captured before an action commits. Unmount/account generations reject private stale replies; order requests bind expected account to current cookie.

Final preservation hardening exposes incomplete legacy payment as explicit null/unknown, never fabricated unpaid/paid/history; confirmation rejects absent payment rows. New V0.5 creation still guarantees exactly one unpaid row/history. Eligibility failures identify requested affected IDs/reason and missing delivery returns null quote without fabricated money. Bounded transient transaction retry exhaustion is retryable503; domain rejections are never automatically retried. No policy for QR/refunds, anti-evasion, support suspension or settlement corrections was invented.
