# Frontend

Vite + React + TypeScript cho Hoa Lac Food Ordering Platform.

Xem [hướng dẫn dự án](../README.md) để cài đặt, chạy và kiểm tra.
Yêu cầu sản phẩm: [requirements.md](../docs/requirements.md).

```sh
npm ci
npm run dev
```

Trang hiện tại là bộ khung tối giản; chưa có nghiệp vụ hoặc lời gọi API.
